# WC Free Gifts

Discounts eligible low-priced cart items when the WooCommerce cart contains exactly three or five units.

## Installation

1. Place this directory at `wp-content/plugins/wc-free-gifts/`.
2. Activate WooCommerce, then activate **WC Free Gifts**.

## Usage

Test with three distinct single-quantity items to see the cheapest item priced at zero. With five items, the rule checks the two cheapest lines and their quantities.
